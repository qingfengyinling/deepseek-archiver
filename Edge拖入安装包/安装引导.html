DEEPSEEK ARCHIVER / EDGE

把聊天记录保存为 Word

安装油猴后，把同一文件夹里的 deepseek-archiver.user.js 拖入 Edge 网页区域，即可进入安装确认页。

  1. 安装 Tampermonkey（选择 Microsoft Edge）。
  2. 地址栏输入 edge://extensions，在 Tampermonkey 的“详细信息”里开启允许访问文件 URL。
  3. 开启允许用户脚本；没有这个选项时，在扩展管理页开启开发人员模式。若提示授予脚本运行权限，请允许。
  4. 拖入 deepseek-archiver.user.js，在油猴确认页点击安装。
  5. 打开并登录 DeepSeek，刷新后在右下角使用DeepSeek 归档 · Word。

打开油猴安装脚本

如果按钮只显示代码，请从文件夹拖入脚本；仍无法安装时，在油猴“管理面板 → 实用工具 → 导入 → 选择文件”中选择该脚本。也可“添加新脚本”，粘贴脚本全部内容后按 Ctrl+S。

ZIP 请先解压。脚本不需要 Python。保留原版导出功能；真实账号接口和浏览器安装结果需在你的 Edge 中确认。
